## Bahasa Indonesia

### Tentang

Organisasi ini dibuat oleh **Andy Satria Budi Utomo**, mahasiswa **Politeknik Elektronika Negeri Surabaya (PENS)**, angkatan **TRI C 2026**, untuk mengumpulkan seluruh tugas coding selama kuliah dalam satu tempat yang rapi dan mudah ditelusuri.

Organisasi ini bersifat personal (hanya dikelola oleh satu orang) dan akan terus bertambah isinya seiring berjalannya semester.

### Struktur Repository

Setiap repository mewakili satu mata kuliah pada semester tertentu, dengan format penamaan:

```
<Nama-Mata-Kuliah>-Semester-<Angka>
```

Di dalam setiap repository, biasanya juga akan disertakan **tautan Google Drive** berisi laporan praktikum/tugas untuk mata kuliah tersebut selama satu semester.

## English

### About

This organization was created by **Andy Satria Budi Utomo**, a student at **Politeknik Elektronika Negeri Surabaya (PENS)**, class of **TRI C 2026**, to collect all coding assignments from his studies in one organized, easy-to-browse place.

This is a personal organization (managed by a single person) and will keep growing as new semesters progress.

### Repository Structure

Each repository represents one subject for a given semester, following this naming convention:

```
<Subject-Name>-Semester-<Number>
```

Each repository will typically also include a **Google Drive link** containing the lab/assignment reports for that subject throughout the semester.
